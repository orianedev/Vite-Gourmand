# Vite-Gourmand
ECF pour titre professionnel Graduate développeur Angular de studi

Vite & Gourmand est un site web de restauration développé dans le cadre d’un projet de développement web.  
L’objectif du projet est de permettre aux utilisateurs de consulter des menus, créer un compte, se connecter et passer des commandes en ligne à travers une interface moderne et intuitive.

Le projet a été réalisé avec les technologies HTML, CSS, PHP et MySQL.
